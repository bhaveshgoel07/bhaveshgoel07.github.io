# Bhagavad Gita · Reader

An elegant, dependency-free static reader for the 700 verses of the Bhagavad Gita.

- Sanskrit shlokas and Devanagari text (aligned to the 700-verse numbering)
- English prose translation prepared from the provided text
- Transliteration, chapter switching, full-text search, bookmarking, shareable verse URLs
- Dark mode, text sizing, responsive layout, saved preferences

Visit: https://bhaveshgoel.me/gita/ (once GitHub Pages deploys the latest changes).

## Run locally

Open `index.html` in a browser, with `data.js` alongside it. This site requires no build step, package manager or backend. Optional Google Fonts need an internet connection; system fallbacks are provided.

## Sources and editorial note

Sanskrit and transliteration adapted from [AdiyogiArts/gita-json](https://github.com/AdiyogiArts/gita-json) under the MIT License. See [SOURCE_LICENSE.txt](SOURCE_LICENSE.txt) for the full license.

The English text is an independently prepared prose translation based on the user's uploaded Sanskrit Bhagavad Gita. The source scan contains OCR errors; these have been corrected where possible for readable alignment. Chapter 13 follows the 34-verse sequence in the supplied translation; the Sanskrit dataset uses an additional introductory verse for that chapter, hence the numbering shift. This is intended for reading rather than philological citation.
